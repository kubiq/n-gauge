# Image assets

Source pictures for the images compiled into the firmware. The `.c` files in
`firmware/car_gauge_v1/` are generated from these by `scripts/png2lvgl.py` -
edit the source here and re-run, never the `.c`. The exact commands are in the
script's docstring.

| File | Used as | Where it came from | Licence |
|---|---|---|---|
| `fastback.png` | `car_top` - tyre screen | i30 N Fastback top view, AI-generated by the owner for this project | the project's own (MIT, like the rest) |
| `oil_temp.png` | `icon_oil` - oil screen | oil-temperature warning-light symbol, made by the owner for this project | the project's own (MIT) |
| `coolant_temp.webp` | `icon_coolant` - oil screen | coolant-temperature warning-light symbol, made by the owner for this project | the project's own (MIT) |
| `turbo.jpg` | `icon_turbo` - boost screen | turbocharger line icon, made by the owner for this project | the project's own (MIT) |
| `satellite.jpg` | `icon_sat` - GPS screen | satellite line icon, made by the owner for this project | the project's own (MIT) |
| `flag_sports_score.svg` | `icon_flag` - track screen | Google Material Symbols, `sports_score` (outlined, 48 px) | Apache License 2.0 - <https://github.com/google/material-design-icons> |

`icon_flag` is rendered from the SVG first:

    rsvg-convert -w 480 -h 480 firmware/assets/flag_sports_score.svg -o /tmp/flag480.png

A shutterstock preview of a chequered flag was offered and not used: it is an
unlicensed, watermarked preview.
